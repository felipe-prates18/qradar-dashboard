Boas práticas de cadastro

  • Utilize padrão nome.sobrenome para consistência.
  • Configure uma senha temporária e oriente o usuário a alterá-la no primeiro acesso.
  • Conceda permissões específicas apenas quando necessário.
  • Use o acesso de administrador apenas para perfis responsáveis por governança.
Dica
Prefira cadastrar permissões antes de criar usuários para agilizar a atribuição.
